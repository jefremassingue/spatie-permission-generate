# Changelog

All notable changes to `jefremassingue/spatie-permission-generate` will be documented in this file

## 1.1.0 - 2026-11-10

- Support `spatie/laravel-permission` 7.x and 8.x
- Install the latest stable release without specifying a version (`composer require jefremassingue/spatie-permission-generate`)
- Fix the package facade alias
- Add the correctly spelled `changeGuardWithPrefix()` method (the old `chanteGuardWithPrefix()` is kept as a deprecated alias)
- Fix the test namespace autoloading
- Publish the configuration under the `spatie-permission-generate-config` tag
- Remove the eager class autoloading
